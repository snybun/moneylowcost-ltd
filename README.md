## ✨ Features & Highlights

- 🍏 **Apple UI Design System**: Translucent glassmorphism (`backdrop-filter: blur`), dark mode typography hierarchy, glowing ambient halos, and smooth micro-interactions.
- ⚡ **Automated Live Calculator**: Real-time currency exchange rates (ILS to PHP, INR, NPR, MDL, GEL, USD), fee breakdown ($0 transparent transfer), and instant payout estimates.
- 🗺️ **Searchable Branch Directory**: Interactive branch locator with city filtering (Tel Aviv, Haifa, Jerusalem, Netanya, Ashdod), phone hotlines, and instant Google Maps directions.
- 🛡️ **Member Perks Bento Grid**: Highlights foreign worker health insurance, local mobile data SIM packages, eyeglasses vision vouchers, and nationwide guided country tours.
- 🔐 **Bank-Grade Spec Callouts**: 256-bit encryption, official regulatory license badges, and 24/7 multi-language customer support (English, Tagalog, Hebrew, Spanish).
- 📲 **Interactive Portal Modal**: Simulated registration and login drawer with celebratory particle effects.

## 🚀 Quick Start (Local Development)

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/snybun/moneylowcost-ltd.git
cd moneylowcost-ltd
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to preview the website live.

### 3. Build for Production
```bash
npm run build
```
The optimized bundle will be compiled into the `dist/` directory, ready for deployment on **Vercel**, **Netlify**, or **GitHub Pages**.
